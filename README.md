
# hy2-reality-optimized.sh — Hysteria2 + Reality 二合一安装脚本 (优化版)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ajksgh/hy2-reality/main/hy2-reality-optimized.sh)
```

需要 root：

```bash
sudo bash <(curl -fsSL https://raw.githubusercontent.com/ajksgh/hy2-reality/main/hy2-reality-optimized.sh)
```

# 直接装某一项（跳过菜单）：

# 装 Hysteria2
```
bash <(curl -fsSL https://raw.githubusercontent.com/ajksgh/hy2-reality/main/hy2-reality-optimized.sh) hy2
```
# 装 Reality
```
bash <(curl -fsSL https://raw.githubusercontent.com/ajksgh/hy2-reality/main/hy2-reality-optimized.sh) reality
```
# 端口跳跃装 HY2
```
HY2_HOP=1 bash <(curl -fsSL https://raw.githubusercontent.com/ajksgh/hy2-reality/main/hy2-reality-optimized.sh) hy2
```

已确认你的 raw 链接返回 **200**，可以正常拉取。
